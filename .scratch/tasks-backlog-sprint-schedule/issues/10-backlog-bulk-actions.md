# 10: Backlog bulk actions

**What to build:** Several backlog tasks can be selected and acted on at once: move to sprint, change status, assign, or delete. The selection is obvious, clearing it is one action, and a bulk change is undoable as a single step.

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] Multi-select works with mouse, touch and keyboard
- [ ] Bulk move to sprint, status change, assign and delete all succeed
- [ ] A selection bar shows the count and clears in one action
- [ ] The action applies to exactly the selected set and nothing else
- [ ] One undo reverses an entire bulk action
- [ ] Selection survives reordering but clears on navigation
