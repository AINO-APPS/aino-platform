# 24: Command palette and shortcuts

**What to build:** One keyboard entry point searches tasks by key or title, jumps to any view, and runs the common actions. A documented shortcut set ships with it and is discoverable from a help overlay.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] The palette opens on the primary modifier plus K and closes on escape
- [ ] Searching by key or title returns tasks; selecting one opens it
- [ ] Every view is reachable from the palette
- [ ] Common actions run from the palette
- [ ] The shortcut help overlay lists the complete set
- [ ] No focus trap; the palette is fully operable by keyboard alone
