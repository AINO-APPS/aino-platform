# 16: Scope baseline surfaced

**What to build:** A sprint records what it committed when it started, and shows scope added and removed since. "Why didn't we finish" gains an answer without leaving the sprint.

**Blocked by:** 15

**Status:** ready-for-agent

- [ ] Starting a sprint records committed points and the committed task set
- [ ] Adding or removing scope after start re-records the baseline with a reason
- [ ] The sprint shows scope added and removed in points
- [ ] A sprint with no scope change shows zero, not a blank
- [ ] The record is immutable for a completed sprint
