# 19: Calendar overlays

**What to build:** The calendar shows approved leave, holidays and booked meetings behind tasks as read-only context, each independently toggleable, so it is obvious why a day has no capacity. No new capacity model is introduced.

**Blocked by:** 18

**Status:** ready-for-agent

- [ ] Leave, holidays and meetings render as background context for their days
- [ ] Each overlay type toggles independently
- [ ] Overlays are read-only and cannot be edited from the calendar
- [ ] Overlays do not affect task counts or point totals
- [ ] A day with an all-day absence still allows tasks to be planned on it
